# Avery-Gallagan-Personal-Blog
Week Four Challenge - Personal Blog

This weeks project was to create a two page blog site. The first page includes the form with inputs for a username, title, and the blog content. There is also a light and dark mode feature implemented on both pages. 

Once the submit button is clicked, it redirects you to the blog.html page where it shows all the blogs that have been posted. This is done through the use of local storage. There is also a back button on this page that will take you back to the form page. 

This project used html, css, and javascript.
